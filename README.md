# Module 11 Challenge

## **Overview**
This project involves web scraping and analyzing data related to Mars. The challenge covers:
1. Use Splinter to automate browsing and load the Mars News Site
2. Use Beautiful to extract the titles and preview texts of news articles 
3. Store the data in a list of dictionaries with keys title and preview 

## **Technologies Used**
- Splinter for automated browsing
- Beautiful Soup for HTMP parsing
- Pandas for data manipulation and analysis 
- Matplotlib for visualization
- CSV files of data input

## **Setup Instructions**
1. **Install the Dependencies:**
Splinter, beautifulsoup4, pandas, matplotlib are installed 

2. **Download ChromeDriver:**
Downloaded the version of ChromeDriver that best matches the Chrome browser version installed in computer

3. **Run Jupyter Notebook:**
Run the queries in jupyter for both mars_news and mars_weather for scraping and analyzing Mars news and mars weather data

4. **Export Results:** 
Export the DataFrame containing Mars weather data to a CSV file 

5. **Verify Outputs:** 
- Ensure the Mars News Data contains a list of dictionaries containing titles and preview texts from Mars news articles. 
- The Mars weather data must be in a csv file that contains the cleaned weateher dataset.
